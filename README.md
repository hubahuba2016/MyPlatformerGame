🛡️ MyPlatformerGame

A fun 2D Android platformer where you play as a brave knight — stomp archers, dash past arrows, and avoid falling to your doom! 
GitHub

🚀 This game was built using Unity and designed to run on Android devices.

📌 About

MyPlatformerGame is a 2D action platformer created in Unity. Players take on the role of a knight navigating levels full of dangerous archers and obstacles. Jump, stomp, and survive as long as you can! 
GitHub

🎮 Features

🛡️ Knight character with responsive movement

🎯 Enemies: Archers that fire arrows

🏆 Score system based on survival time and kills

⬆️ Jump & stomp mechanics

⛔ Hazards like pitfalls and moving platforms

📱 Android-optimized controls

📦 Technologies

This project uses:

Unity — for development and building the game

C# — for game logic and scripting

Android SDK — for building the APK
GitHub

📥 How to Play

Install the game on your Android device (APK file).

Open the app to start the game.

Use on-screen controls to move and jump.

Stomp enemies or avoid them to survive.

Don’t fall off the platforms!
